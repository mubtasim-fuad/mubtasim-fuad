# Pharmacy Sales & Inventory Analytics

**Tools:** Excel, SQL, SQLite and Power BI/DAX.

Portfolio practice project analyzing synthetic retail pharmacy records: products, sales transactions and purchasing.

## Questions answered
- How does monthly revenue change?
- Which products sell the most?
- Which products need replenishment?
- What categories account for the most sales?

The full offline project package includes CSVs, SQLite database, Excel dashboard, HTML preview and chart screenshot. Use SQL queries and follow the Power BI setup guide to build a native dashboard.

**All financial figures are fictional.** This demonstration is not actual customer or store data.

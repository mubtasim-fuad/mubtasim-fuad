# Overseas Recruitment Analytics

**Tools:** Excel, SQLite, SQL, Power BI/DAX.

Exploratory analysis of 1,500 **synthetic** overseas recruitment applications, including deployment rates, country breakdowns, average processing time and application status. No data from Greenland Overseas or real candidates is used.

## How to run
1. Open the CSV dataset in Excel or import it into SQLite.
2. Run the queries in `sql/analysis.sql`.
3. Follow `powerbi/POWER_BI_SETUP.md` to build the Power BI report.
4. Validate counts and deployment rate against Excel.

## Outputs
Excel dashboard, interactive HTML preview and SQL reporting are available in the downloadable project archive. A native Power BI `.pbix` has **not** been completed yet.

## Data ethics
Demonstration only; all recruitment records and figures are fictional.

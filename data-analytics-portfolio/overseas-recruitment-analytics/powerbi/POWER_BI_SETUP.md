# Power BI Setup
1. Open Power BI Desktop → Get Data → Text/CSV and load `candidates.csv` from the project archive.
2. In Power Query check data types, missing values and candidate ID uniqueness.
3. Rename the table to `Candidates` and select Close & Apply.
4. Add the measures in `MEASURES_DAX.txt`.
5. Add cards for Total Candidates, Total Deployed, Deployment Rate and Avg Processing Days.
6. Add a country bar chart, a status chart and slicers for Country and Recruiter.
7. Validate KPI totals against Excel and save the report as `Recruitment_Analytics.pbix`.

**Status:** This is a build recipe, not a native .pbix file.

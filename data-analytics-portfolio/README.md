# Data Analytics Portfolio

Three portfolio projects for junior data analyst roles. All sample datasets are synthetic and not from Greenland Overseas.

- [Overseas Recruitment Analytics](./overseas-recruitment-analytics/README.md) — Excel, SQL, SQLite, DAX/Power BI setup
- [Pharmacy Sales Analytics](./pharmacy-sales-analytics/README.md) — Excel, SQL, inventory and revenue reports
- [Automated Data Cleaning](./automated-data-cleaning/README.md) — Python, Pandas, validation and report exports

Note: The source data, SQLite databases, Excel workbooks and screenshots are packaged separately until they can be uploaded. Power BI `.pbix` reports have not yet been authored.

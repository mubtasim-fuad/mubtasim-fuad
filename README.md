## About

I graduated in CSE from North South University in 2025. My work combines full-stack software with a background in Python and computer vision. I like projects that make a useful flow easy to understand and demonstrate end to end.

Currently focused on Angular, ASP.NET Core, SQL, and building stronger production habits through practical projects.

- Building web interfaces and APIs with Angular, React, ASP.NET Core, Node.js, and Express.
- Working with PostgreSQL and SQLite for application data.
- Exploring computer vision with Python, OpenCV, and scikit-learn.
- Documenting trade-offs and testing the behavior that matters most.
